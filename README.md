# 📖 Quote Diary

A web application designed to store, manage, and interact with quotes and personal diary entries. Built with Python on the backend and an interactive HTML/CSS/JavaScript web interface.

---

## ✨ Features

- **Interactive Interface:** Browse, search, and organize your quotes and journal entries dynamically.
- **Persistent Data Storage:** Saves entries locally in structured JSON format (`data/journal.json`).
- **Clean UI & Styling:** Styled with modern CSS and modular JavaScript for smooth interaction.

---

## 🛠️ Tech Stack

- **Backend:** Python
- **Frontend:** HTML5, CSS3, JavaScript (`app.js`, `w3.css`)
- **Package Manager:** Poetry
- **Data Store:** JSON (`journal.json`)
